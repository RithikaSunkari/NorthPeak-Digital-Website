## 📌 Project Overview

NorthPeak Digital is a fictional digital agency website designed to showcase modern web development services.

The website focuses on:
- Clean UI design
- Responsive layouts
- Performance optimization
- Accessibility best practices
- SEO-friendly structure


## 🚀 Features

- Responsive design for mobile, tablet and desktop
- Hero section with CTA buttons
- Services section with 6 service cards
- Why Choose Us section
- Featured projects showcase
- Client testimonials
- 3-tier pricing section
- Contact form with validation
- Mobile navigation menu
- Accessibility improvements
- Optimized loading performance


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify (Deployment)
- Git & GitHub


## ⚡ Performance Optimization

The website was optimized to improve Lighthouse scores.

Improvements made:
- Added image width and height attributes
- Implemented lazy loading for images
- Improved semantic HTML structure
- Added accessible form labels
- Fixed color contrast issues
- Optimized resource loading
